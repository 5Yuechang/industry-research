# industry-research · 行业调查 Skill

一个 Claude Code skill，把"行业调查"方法论固化为可复用流程：

1. **提出问题**：从调研动机出发，拆分问题
2. **初步搜索关键词**：搜索引擎、公众号/知乎、现成研报、播客
3. **深入搜索更多关键词**：左右对照法扩充关键词，整理行业术语
4. **整理归纳**：通用商业框架 / 通用社会问题框架
5. **尝试回答综合性的高级问题**：合上笔记，自问自答

并提示补充 **资深专家调研** 与 **学术性调研**。

## 安装

```bash
git clone https://github.com/<your-username>/industry-research.git ~/.claude/skills/industry-research
```

## 使用

在 Claude Code 中说"帮我调研一下 XX 行业"，或输入 `/industry-research`。
